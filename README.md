# 视频小窗 Mini Player

Chrome / Edge / Arc 等 Chromium 浏览器扩展：当页面主视频滚出视口时，在右下角显示可操控的小播放框。

## 功能

- 自动识别页面主视频（优先正在播放、面积较大的 `<video>`）
- 主播放框可见时隐藏小窗；滚出后显示右下角小窗
- 小窗实时镜像画面（canvas），播放/暂停、进度条控制原视频
- 点击画面或「↺」平滑滚回主视频
- 可拖动小窗位置；「✕」关闭本次小窗（滚回主视频后会重新启用）
- 弹窗开关可全局启用/关闭

## 安装

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」
4. 选择本目录：`browser-extension-video-miniplayer`

## 使用

1. 打开任意带 HTML5 视频的页面（B 站、YouTube 等）
2. 开始播放后向下滚动，直到主视频离开屏幕
3. 右下角出现小窗；可暂停、拖进度、点回主视频

## 说明

- 部分 DRM / 跨域视频无法把画面画到 canvas（小窗会显示占位提示），但仍可控制播放与回到主视频
- 站点使用自定义播放器时，扩展仍绑定底层 `<video>` 元素
- 不依赖系统级画中画（PiP），小窗固定在网页内
